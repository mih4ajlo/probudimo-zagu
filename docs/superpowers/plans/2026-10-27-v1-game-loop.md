# Probudimo Zagu v1 Game Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a playable browser game where the princess walks one overworld, talks to three ranked lords (10 / 20 / 30 points), earns each lord’s points once, and reaches an ending.

**Architecture:** Pure TypeScript modules own lords, score, dialog, and “all visited.” Kaplay scenes (title, wake, overworld, ending) only draw, take input, and call those modules. One in-memory session holds score; dialog state is per scene.

**Tech Stack:** Kaplay `^3001.0.19` (stable, not 4000 alpha), TypeScript, Vite, Vitest, Playwright. Static site, no server, no React/Phaser/Jest/Cypress.

**Spec:** `docs/game-design.md`  
**Testing spec:** `docs/testing.md`

## Global Constraints

- One overworld map; lords are markers on that map (not indoor rooms).
- Dialog is linear per lord; no branching trees.
- Points grant only on the first visit; repeat talk is allowed.
- Movement is blocked while a dialog box is open.
- Advance dialog with Space, Enter, or click.
- Walk with WASD or arrow keys.
- Three lords, one per rank: rank 1 = 10 points, rank 2 = 20, rank 3 = 30 (max score 60).
- No combat, inventory, extra maps, save/load, or backend.
- Vitest for logic; one Playwright smoke (page loads, canvas present, no `pageerror`).
- Do not import Kaplay into unit tests or into `src/score.ts`, `src/dialog.ts`, `src/progress.ts`, `src/data/*`.
- Pixel size: 16×16 tiles; integer scale; `crisp: true`; no texture smoothing.
- Placeholder copy in English (language still open; swap strings in `src/data/` later).
- Kaplay context object `k` only — no Kaplay globals.

## Locked interfaces

```typescript
export type LordId = "north" | "east" | "west";
export type LordRank = 1 | 2 | 3;

export const RANK_POINTS: Record<LordRank, number> = {
  1: 10,
  2: 20,
  3: 30,
};

export type Lord = {
  id: LordId;
  name: string;
  rank: LordRank;
  marker: string;
  lines: readonly string[];
  points: number;
};

export const LORDS: readonly Lord[];
export function getLord(id: LordId): Lord;
export function lordByMarker(marker: string): Lord | undefined;
export function maxScore(): number;

export type ScoreState = {
  total: number;
  visited: string[];
};

export function createScore(): ScoreState;
export function visitLord(state: ScoreState, id: string): { granted: number };

export type DialogState = {
  lines: string[];
  index: number;
  open: boolean;
};

export function createDialog(): DialogState;
export function openDialog(state: DialogState, lines: readonly string[]): void;
export function advanceDialog(state: DialogState): void;
export function isMovementBlocked(state: DialogState): boolean;
export function currentLine(state: DialogState): string | null;

export function isReadyForEnding(
  visited: readonly string[],
  lordIds: readonly string[],
): boolean;

export function resetSession(): { score: ScoreState };
export function getSession(): { score: ScoreState };
```

`visitLord` looks up `LORDS` by `id`. Unknown id → `{ granted: 0 }`, do not push to `visited`, do not throw. Known first visit → `{ granted: lord.points }`, append id, add points. Known repeat → `{ granted: 0 }`.

`openDialog` with a non-empty list sets `open: true`, `index: 0`. Empty list leaves `open: false` and does not block movement.

`advanceDialog` on the last line sets `open: false`. If already closed, it is a no-op.

## Review Focus

- Unknown lord id passed to `visitLord` — grant 0, do not throw, do not mark visited (Task 2).
- `openDialog` with `[]` — movement stays unblocked (Task 3).
- Two of three lords visited — `isReadyForEnding` is false (Task 4).
- Rank 2 visit grants 20, not 10 (Task 1–2).
- Overlapping a lord while a box is already open — do not re-open or double-grant (Task 7).
- WASD and arrow keys both move; Space, Enter, and click all advance the same dialog (Tasks 6–7).

```typescript
import { LORDS } from "./data/lords";

export type ScoreState = {
  total: number;
  visited: string[];
};

export function createScore(): ScoreState {
  return { total: 0, visited: [] };
}

export function visitLord(state: ScoreState, id: string): { granted: number } {
  const lord = LORDS.find((item) => item.id === id);
  if (!lord) {
    return { granted: 0 };
  }
  if (state.visited.includes(id)) {
    return { granted: 0 };
  }
  state.visited.push(id);
  state.total += lord.points;
  return { granted: lord.points };
}
```

```typescript
export type DialogState = {
  lines: string[];
  index: number;
  open: boolean;
};

export function createDialog(): DialogState {
  return { lines: [], index: 0, open: false };
}

export function openDialog(state: DialogState, lines: readonly string[]): void {
  if (lines.length === 0) {
    state.lines = [];
    state.index = 0;
    state.open = false;
    return;
  }
  state.lines = [...lines];
  state.index = 0;
  state.open = true;
}

export function advanceDialog(state: DialogState): void {
  if (!state.open) {
    return;
  }
  if (state.index >= state.lines.length - 1) {
    state.open = false;
    return;
  }
  state.index += 1;
}

export function isMovementBlocked(state: DialogState): boolean {
  return state.open;
}

export function currentLine(state: DialogState): string | null {
  if (!state.open) {
    return null;
  }
  return state.lines[state.index] ?? null;
}
```

```typescript
import { WAKE_LINES } from "../data/story";
import {
  advanceDialog,
  createDialog,
  currentLine,
  openDialog,
} from "../dialog";
import { k } from "../kaplayContext";

export function registerWakeScene(): void {
  k.scene("wake", () => {
    const dialog = createDialog();
    openDialog(dialog, WAKE_LINES);

    const box = k.add([
      k.rect(300, 48),
      k.pos(10, 122),
      k.color(12, 10, 20),
      k.outline(1, k.rgb(220, 200, 140)),
    ]);

    const line = k.add([
      k.text(currentLine(dialog) ?? "", { size: 8, width: 280 }),
      k.pos(18, 130),
    ]);

    function refresh(): void {
      const text = currentLine(dialog);
      if (text === null) {
        k.go("overworld");
        return;
      }
      line.text = text;
    }

    function next(): void {
      advanceDialog(dialog);
      refresh();
    }

    k.onKeyPress("space", next);
    k.onKeyPress("enter", next);
    k.onClick(next);
  });
}
```

Keep `box` so the dialog has a visible panel. Do not move a player in this scene.

Map (walls `#`, floor `.`, player `@`, lords use each `lord.marker`):

```typescript
import { LORDS, getLord, type LordId } from "../data/lords";
import {
  advanceDialog,
  createDialog,
  currentLine,
  isMovementBlocked,
  openDialog,
} from "../dialog";
import { k, TILE } from "../kaplayContext";
import { isReadyForEnding } from "../progress";
import { getSession } from "../session";
import { visitLord } from "../score";

const SPEED = 80;

export function registerOverworldScene(): void {
  k.scene("overworld", () => {
    const session = getSession();
    const dialog = createDialog();
    const lordIds = LORDS.map((lord) => lord.id);

    k.addLevel(
      [
        "####################",
        "#..................#",
        "#..N...............#",
        "#..................#",
        "#........@.........#",
        "#..................#",
        "#...............E..#",
        "#..W...............#",
        "#...............S..#",
        "####################",
      ],
      {
        tileWidth: TILE,
        tileHeight: TILE,
        tiles: {
          "#": () => [
            k.rect(TILE, TILE),
            k.color(40, 32, 56),
            k.area(),
            k.body({ isStatic: true }),
          ],
          ".": () => [k.rect(TILE, TILE), k.color(48, 72, 48)],
          N: () => lordTile("north"),
          E: () => lordTile("east"),
          S: () => lordTile("south"),
          W: () => lordTile("west"),
        },
      },
    );

    const player = k.add([
      k.rect(TILE - 2, TILE - 2),
      k.color(220, 180, 210),
      k.pos(10 * TILE, 4 * TILE),
      k.anchor("center"),
      k.area(),
      k.body(),
      "player",
    ]);

    const hud = k.add([
      k.text(hudText(), { size: 8 }),
      k.pos(8, 8),
      k.fixed(),
    ]);

    const dialogBox = k.add([
      k.rect(300, 48),
      k.pos(10, 122),
      k.color(12, 10, 20),
      k.fixed(),
      k.opacity(0),
    ]);

    const dialogText = k.add([
      k.text("", { size: 8, width: 280 }),
      k.pos(18, 130),
      k.fixed(),
    ]);

    function lordTile(id: LordId) {
      return [
        k.rect(TILE, TILE),
        k.color(180, 140, 40),
        k.area(),
        k.body({ isStatic: true }),
        "lord",
        { lordId: id },
      ];
    }

    function hudText(): string {
      return `Score ${session.score.total}   Lords ${session.score.visited.length}/${lordIds.length}`;
    }

    function refreshDialog(): void {
      const text = currentLine(dialog);
      if (text === null) {
        dialogBox.opacity = 0;
        dialogText.text = "";
        if (isReadyForEnding(session.score.visited, lordIds)) {
          k.go("ending");
        }
        return;
      }
      dialogBox.opacity = 1;
      dialogText.text = text;
    }

    k.onCollideStart("player", "lord", (_player, lord) => {
      if (isMovementBlocked(dialog)) {
        return;
      }
      const id = (lord as { lordId?: LordId }).lordId;
      if (!id) {
        return;
      }
      const data = getLord(id);
      visitLord(session.score, id);
      hud.text = hudText();
      openDialog(dialog, data.lines);
      refreshDialog();
    });

    function next(): void {
      if (!isMovementBlocked(dialog)) {
        return;
      }
      advanceDialog(dialog);
      refreshDialog();
    }

    k.onKeyPress("space", next);
    k.onKeyPress("enter", next);
    k.onClick(next);

    k.onUpdate(() => {
      if (isMovementBlocked(dialog)) {
        return;
      }
      const left = k.isKeyDown("left") || k.isKeyDown("a");
      const right = k.isKeyDown("right") || k.isKeyDown("d");
      const up = k.isKeyDown("up") || k.isKeyDown("w");
      const down = k.isKeyDown("down") || k.isKeyDown("s");
      const x = (Number(right) - Number(left)) * SPEED;
      const y = (Number(down) - Number(up)) * SPEED;
      player.move(x, y);
      k.camPos(player.pos);
    });
  });
}
```

If `addLevel` does not spawn `@`, keep the explicit `player` `k.add` as above and treat `@` as empty space in `tiles` (`"@": () => []`) or omit `@` from the map string and keep the hardcoded spawn.

If `k.body()` on the player requires `k.setGravity(0)`, set gravity to 0 in `kaplayContext.ts` (`gravity: 0` if supported, otherwise `k.setGravity(0)` at the start of the overworld scene) so this stays top-down, not a fall-down platformer.

```typescript
import { ENDING_LINES, TITLE } from "../data/story";
import { LORDS } from "../data/lords";
import { k } from "../kaplayContext";
import { getSession } from "../session";

export function registerEndingScene(): void {
  k.scene("ending", () => {
    const session = getSession();
    k.add([
      k.text(TITLE, { size: 14 }),
      k.pos(k.width() / 2, 28),
      k.anchor("center"),
    ]);
    k.add([
      k.text(ENDING_LINES.join("\n"), { size: 8, width: 280 }),
      k.pos(k.width() / 2, 72),
      k.anchor("center"),
    ]);
    k.add([
      k.text(
        `Score ${session.score.total} / ${LORDS.length * 10}`,
        { size: 10 },
      ),
      k.pos(k.width() / 2, 120),
      k.anchor("center"),
    ]);
    k.add([
      k.text("Press Enter for title", { size: 8 }),
      k.pos(k.width() / 2, 150),
      k.anchor("center"),
    ]);
    k.onKeyPress("enter", () => k.go("title"));
  });
}
```
